# BJT 어휘·문법 드릴

BJT 독해1(어휘·문법) 대비 드릴 — 아이패드 사파리·크롬에서 https://qslns.github.io/bjt-grammar/ 로 열어 씀.

- A 핵심 108포인트 코스(11/7~11/9 새 포인트 → 11/10 복습·최종 확인 → 11/11 남은 복습), B·C 확장·보험 포인트
- 음성: Microsoft 나나미·게이타(미리 녹음, audio/)
- 진도는 그 브라우저에 저장(설정 › 진도 코드로 옮기기)
- version.json = 지금 판 번호. 페이지가 열릴 때·탭으로 돌아올 때 확인해서 새 판이면 알아서 다시 불러옴(푸는 중엔 홈으로 나올 때)
